How this works

A local Python process runs the actual CivicOS governance commands, vote/recusal checks and deterministic SciPy portfolio optimizer. Each run has its own transaction history and verification digest. Where a proposal is rejected, the engine does not create its portfolio baseline or synthetic funding commitment.
