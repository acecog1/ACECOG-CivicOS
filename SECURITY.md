# Security

This is a pre-release prototype. Caller authentication is not implemented, so the development API is local-only. Do not use it for real civic records, binding decisions, production tenants or financial execution. The static walkthrough uses synthetic data and grants no real authority.

Report vulnerabilities privately to **morgan@acecog.org**, or through GitHub private vulnerability reporting when enabled. Do not post secrets or private records in public issues. Include a synthetic reproduction, affected version and expected impact.

Repository CI checks tests, generated contracts, dependency vulnerabilities, static analysis and an SBOM. Those checks reduce specific risks; they do not certify the system secure, legally authorized or ready for public interaction. Independent security/accessibility/legal review and explicit deployment approval are separate requirements.
